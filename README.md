# 具身触觉汇报视觉原型

这是从论文《面向具身交互的触觉感知：从传感、理解到闭环交互》中提炼的四屏交互式视觉样片，用于讨论汇报风格与展示方式，并非最终 30 分钟版本。

四个代表性屏幕分别展示：

1. 触觉价值与三条第一性命题；
2. 七类触觉传感范式的双轴地图与任务匹配；
3. 从接触到策略的八阶段处理链及部署层；
4. 具身触觉神经系统、快慢通路和未来技术路线。

页面内置“冷静的触觉实验室”和“科学图谱”两套主题。所有可视化均为本地 SVG/CSS，无在线字体、图片或 CDN 依赖。

## 运行

最方便的方式是双击 `start-prototype.cmd`，它会启动本地服务器并打开浏览器。

也可以在 PowerShell 中运行开发版本：

```powershell
npm.cmd install
npm.cmd run dev
```

构建离线静态文件：

```powershell
npm.cmd run build
```

构建结果位于 `dist/`。由于浏览器对 ES Module 的限制，请通过本地 HTTP 服务打开，不要直接双击 `dist/index.html`。

## 操作

- `←` / `→` 或空格：切换屏幕
- `T`：切换“触觉实验室 / 科学图谱”主题
- `E`：打开当前屏幕的证据面板
- `F`：进入或退出全屏
- `H`：显示快捷键帮助
